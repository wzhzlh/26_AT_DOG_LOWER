# 2026_AT_DogLower
河北科技大学 四足机器人 STM32H723代码

## 轮腿电机与 USB 协议

485_1 连接前腿，485_2 连接后腿。每条总线上左腿关节 ID 为 1、2、3，轮子 ID 为 4；右腿关节 ID 为 5、6、7，轮子 ID 为 8。实际电机 ID 需事先配置。四个轮子的方向在 `MyTask/run.c` 的 `leg` 中通过 `inv_wheel` 设置，当前均为 1，反向时改为 -1。

USB 数据使用 `MyTask/run.h` 中的 1 字节对齐结构体，float 和整数为小端格式。腿顺序为左前、右前、左后、右后：

- 下行 `MotorTargetPack_t`（280 字节，类型 0x04）：每条腿依次为 3 个关节的 `rad, omega, torque, kp, kd`，以及轮子的 `omega, kd`，末尾为 `timestamp`。轮子 `omega` 为输出端角速度（rad/s），`kd` 为直接发送给电机的速度增益。原轮子 `torque` 字段位置改为 `kd`，上位机必须同步修改。
- 上行 `MotorStatePack_t`（252 字节，类型 0x03）：每条腿依次为 3 个关节及 1 个轮子的 `rad, omega, torque`，随后是 4 个轮子状态的独立副本，末尾为 `watch_dog`、`timestamp`、`motor_error`。轮子角度相对上电初始化位置，轮速和力矩按 6.33 减速比换算。上位机必须同步修改接收结构体。
- `watch_dog` 按腿顺序每腿占 4 位，分别对应 3 个关节和轮子；电机连续掉线超过 80 次 TIM13 回调后置位，通信恢复后清零。初始化需要 16 个电机均正常通信，上位机指令超时时轮速和轮子 Kd 清零。

请在轮子离地时逐一验证电机 ID、轮子方向和速度增益。8 个电机轮询周期及掉线时的总线响应时间也需要在实机测量。
